# Practical Stock Tools

五個可獨立部署的 Streamlit 股票分析工具，聚焦於交易前評估與風險控管：

- 趨勢策略回測：比較均線策略與買入持有。
- 部位與停損計算：用可承受損失反推股數與資金占用。
- 投資組合風險：檢查波動、最大回撤、VaR 與相關性。
- 選擇權實驗室：Black–Scholes 理論價、Greeks 與到期損益。
- 技術訊號回測：組合均線與 RSI 訊號，檢視歷史表現。

## 使用方式

每個資料夾都是一個獨立網頁程式。部署到 Streamlit Community Cloud 時，指定該資料夾中的 `app.py` 為 Main file path。

## 風險聲明

本專案僅供研究與教育用途，不構成投資建議。歷史回測不代表未來績效；市場資料可能延遲、缺漏或因供應商調整而變動。實際交易前請自行確認價格、交易成本、稅費與風險承受能力。
